# hackathon



## Getting started
1. Clone the repo from https://web.git.mil/nevis.rumi/hackathon
    - SSH is not available so you must use username and the contents of token to take any actions.
    - Dev branch is the most up to date but main is the stable and recommended branch to clone

2. Create a .env file in the same file level as the .env.example file. Take the contents from
.env.example and copy them into .env but replace the values to be your actual Ask Sage username
and API key.

3. Create your Python environment
    - After creating your environment, activate it.
    - in terminal, 'pip install pdm'
    - in terminal, 'pdm install' and make sure your terminal's directory is the same as pyproject.toml
